6. Tecnología y Funcionalidades

Frontend Technologies

  • HTML5 para estructura
  • CSS3 para estilos responsivos
  • JavaScript vanilla (sin frameworks)
  • Fetch API para peticiones HTTP
  • localStorage para almacenamiento de tokens

Funcionalidades Implementadas

  • Autenticación con tokens JWT
  • Almacenamiento seguro de tokens
  • Gestión automática de headers Authorization
  • CRUD completo para Spots y Registros
  • Validación de formularios en cliente
  • Mensajes de estado (éxito, error, info)
  • Interfaz responsiva y mobile-friendly
  • Manejo de errores 401 (token inválido)

7. Flujo de Uso Típico

1. Usuario accede a http://localhost:8000/client.html 2. Ve el formulario de login 3. Ingresa credenciales (test@example.com / password) 4. Click en "Iniciar Sesión" 5. El cliente hace POST /api/login 6. Recibe token del servidor 7. Token se guarda en localStorage 8. Interfaz cambia mostrando datos del usuario 9. Usuario puede listar spots/registros 10. Cada petición incluye Authorization header con token 11. Si token expira, peticiones retornan 401 12. Usuario puede hacer logout para revocar token

8. Seguridad

🔒 Medidas de Seguridad Implementadas:
  • ✅ Tokens guardados en localStorage (no en cookies por defecto)
  • ✅ Headers CORS manejados por el servidor
  • ✅ Validación en cliente (primera línea de defensa)
  • ✅ Validación en servidor (defensa principal)
  • ✅ Tokens revocables mediante logout
  • ✅ Manejo seguro de errores
